Core orchestration package. Contains the inspector classes, repository layer, and the HTTP/WebSocket server that broadcasts inspector data to remote UI clients.

## Installation

```yaml
dependencies:
  xray_inspector: ^0.0.1
```

## What's included

- `XRayNetworkInspector` — captures and stores network calls
- `XRayLogInspector` — captures and stores log entries
- `XRayKeyValueInspector` — base class for key-value inspectors
- `XRayInspectorServer` — HTTP + WebSocket + UDP discovery server
- `XRayInspectorServerConfig` — server configuration

## XRayNetworkInspector

```dart
// Dio — wire up via XRayNetworkDioInterceptor
final inspector = XRayNetworkInspector();

// Global dart:io override — captures all HttpClient traffic automatically
final inspector = XRayNetworkInspector(enableHttpOverride: true);
```

| Member                 | Type                       | Description                                                                 |
| ---------------------- | -------------------------- | --------------------------------------------------------------------------- |
| `title`                | `String`                   | Display name (default: `"Network"`)                                         |
| `enableHttpOverride`   | `bool`                     | When `true`, installs a global `dart:io` override to capture all HTTP traffic. Only one inspector can have this enabled at a time. Ignored on web. _(since 0.0.9)_ |
| `id`                   | `String`                   | Derived from title, used as server route ID                                 |
| `calls`                | `List<XRayNetworkCall>`    | Current captured calls (snapshot)                                           |
| `callsNotifier`        | `ValueNotifier<List<...>>` | Reactive calls list                                                         |
| `findById(id)`         | `XRayNetworkCall?`         | Look up a call by ID                                                        |
| `addListener(l)`       | `void`                     | Register a listener                                                         |
| `removeListener(l)`    | `void`                     | Unregister a listener                                                       |
| `clear()`              | `void`                     | Clear all captured calls                                                    |

### Global HTTP override

Pass `enableHttpOverride: true` to capture every HTTP request the app makes through `dart:io`'s `HttpClient` — Dio, `package:http`, and any other client built on `dart:io` — without changing those clients:

```dart
final networkInspector = XRayNetworkInspector(enableHttpOverride: true);
```

- It records the method, URL, request and response headers and bodies, status code, duration and errors of each call.
- Only one `XRayNetworkInspector` can enable it; a second one throws a `StateError`.
- It is ignored on web, where `dart:io` is not available.
- Combined with `xray_network_dio_interceptor`, each Dio call is recorded once, by the Dio interceptor _(since 0.0.11)_.

See [Network Inspection](/guides/network-inspection#setup-with-global-http-override) for more.

## XRayLogInspector

```dart
final inspector = XRayLogInspector(title: 'Logs');
```

| Member                 | Type                          | Description                      |
| ---------------------- | ----------------------------- | -------------------------------- |
| `title`                | `String`                      | Display name (default: `"Logs"`) |
| `entries`              | `List<XRayLogInspectorEntry>` | Current log entries              |
| `entriesNotifier`      | `ValueNotifier<List<...>>`    | Reactive entries list            |
| `verbose(message)`     | `void`                        | Log at verbose level             |
| `debug(message)`       | `void`                        | Log at debug level               |
| `info(message)`        | `void`                        | Log at info level                |
| `warning(message)`     | `void`                        | Log at warning level             |
| `error(message)`       | `void`                        | Log at error level               |
| `log(message, level:)` | `void`                        | Log with explicit level          |
| `clear()`              | `void`                        | Clear all entries                |

## XRayKeyValueInspector

Base class used by `XRaySharedPreferencesInspector` and `XRaySecureStorageInspector`.

```dart
final inspector = XRayKeyValueInspector(source: mySource);
```

| Member              | Type                                          | Description                         |
| ------------------- | --------------------------------------------- | ----------------------------------- |
| `title`             | `String`                                      | Derived from `source.title`         |
| `entriesNotifier`   | `ValueNotifier<List<InspectorKeyValueEntry>>` | Reactive entries                    |
| `refresh()`         | `Future<void>`                                | Re-read all entries from the source |
| `write(key, value)` | `Future<void>`                                | Write a value and refresh           |
| `delete(key)`       | `Future<void>`                                | Delete a key and refresh            |
| `clear()`           | `void`                                        | Delete all keys                     |

## XRayInspectorServer

```dart
final server = XRayInspectorServer(
  config: XRayInspectorServerConfig(
    inspectors: [networkInspector, logInspector],
  ),
);

await server.start();
await server.stop();
```

`XRayInspectorServerConfig` options:

| Option               | Type                       | Description                                                                                                 |
| -------------------- | -------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `inspectors`         | `List<XRayInspector>`      | The inspectors to serve                                                                                     |
| `httpPort`           | `int`                      | HTTP and WebSocket port (default: `7780`). Must be different for each app running on the same device.      |
| `discoveryPort`      | `int`                      | UDP discovery port (default: `7781`). Apps on the same device can share it _(since 0.0.11)_.                |
| `deviceName`         | `FutureOr<String> Function()?` | Shown in the xRay desktop app's device list so devices can be told apart                                |
| `appName`            | `FutureOr<String> Function()?` | Shown in the device list next to the device name                                                        |
| `allowInReleaseMode` | `bool`                     | Start the server in release builds too (default: `false`) _(since 0.0.11)_. See [Release builds](/guides/how-it-works#release-builds). |

Since 0.0.11, in release builds `start()` does nothing unless `allowInReleaseMode` is `true`. See [How it works](/guides/how-it-works) for ports, manual connection and security.

## XRayKeyValueSource

Implement this interface to add any key-value store:

```dart
abstract class XRayKeyValueSource {
  String get title;
  Future<Map<String, String>> readAll();
  Future<void> write(String key, String value);
  Future<void> delete(String key);
}
```
