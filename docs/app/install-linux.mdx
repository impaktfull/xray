The xRay Linux app connects to Flutter apps that run `xray_inspector` on your local network. It is distributed as an AppImage on GitHub Releases: one file that runs on most distributions, without installing anything as root.

## Requirements

- A 64-bit (x86_64) Linux desktop
- An impaktfull account with approved xRay alpha access (see [Account and access](/app/account-and-access))
- A running Flutter app with `xray_inspector` configured (see [Quick Start](/getting-started))
- These system libraries:
  - **GTK 3**, the desktop toolkit xRay is drawn with.
  - **libsecret** and a keyring (GNOME Keyring or KWallet), where xRay stores your sign-in.
  - **WebKitGTK 4.1**, needed by the sign-in component.
  - **FUSE 2**, which AppImages use to run.

Most desktop installations have all of them. If one is missing, install it with your package manager:

```bash
# Ubuntu 24.04 and later
sudo apt install libgtk-3-0 libsecret-1-0 gnome-keyring libwebkit2gtk-4.1-0 libfuse2t64

# Ubuntu 22.04, Debian
sudo apt install libgtk-3-0 libsecret-1-0 gnome-keyring libwebkit2gtk-4.1-0 libfuse2

# Fedora
sudo dnf install gtk3 libsecret gnome-keyring webkit2gtk4.1 fuse-libs

# Arch Linux
sudo pacman -S gtk3 libsecret gnome-keyring webkit2gtk-4.1 fuse2
```

## Install

1. Open the [xRay GitHub Releases page](https://github.com/impaktfull/xray/releases).
2. Download the latest `xRay-<version>-x86_64.AppImage` asset.
3. Make it executable and start it:

```bash
chmod +x xRay-*-x86_64.AppImage
./xRay-*-x86_64.AppImage
```

Keep the AppImage where you saved it: xRay registers that file so your browser can return to it after signing in. To get xRay in your application menu, use an AppImage manager such as [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) or [AppImageLauncher](https://github.com/TheAssassin/AppImageLauncher).

## Update

xRay tells you when a new version is available. Download the new AppImage, make it executable, and remove the old one.

## Sign in and get access

1. Click **Continue with impaktfull**. Your browser opens to finish signing in with your impaktfull account. After you sign in, the browser asks to open xRay: allow it, and the sign-in continues in the app.
2. xRay is in alpha and open to approved testers. The first time, click **Request access**. You get an email once your request is approved; then click **Check again** to start using xRay.

See [Account and access](/app/account-and-access) for what happens to your data and how the free alpha license works.

## Connect to your app

1. Run your Flutter app with `xray_inspector` set up (see [Quick Start](/getting-started)).
2. In xRay, open **Add Connection**. Your app appears under **Discovered on your network**.
3. Click it and enter the pairing code your app printed in its console, on the line that starts with `[xray_inspector] Pairing code:`. xRay remembers it for this app on this device. If the app uses a password or [trusted desktops](/guides/protected-connections#trusted-desktops) instead, enter the password, or connect without a prompt.

If your app does not appear, see [Troubleshooting discovery](/guides/how-it-works#troubleshooting-discovery).
